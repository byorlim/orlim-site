01 — SE VOCÊ QUER OLHAR PARA TRÁS

Diário das Sombras

Comece aqui se você está percebendo padrões que se repetem, sentimentos que não entende completamente ou partes de si que costuma esconder. É uma leitura mais investigativa e íntima.

Afirmações

03 / ORLIM

Para além.

A Orlim nasceu para criar materiais que não tratam a mulher como um conjunto de frases prontas.

Aqui, a pergunta vem antes da fórmula. A contradição não precisa ser apagada para ser compreendida. O desejo não precisa ser diminuído para parecer aceitável. E uma versão antiga de você não precisa continuar no comando só porque foi a primeira que aprendeu a funcionar.

Não é sobre encontrar uma versão perfeita de si. É sobre decidir, com mais consciência, quais versões você ainda escolhe sustentar.
